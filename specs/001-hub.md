# 001 — Hub de rotinas (tela única)

| Campo  | Valor      |
| ------ | ---------- |
| status | feita      |
| data   | 2026-10-15 |

## Objetivo

Uma única tela que apresenta as rotinas disponíveis e executa a rotina escolhida, sem trocar de página.

## Comportamento

1. Sem hash na URL: mostra o título "Escolha uma rotina" e um card por rotina do registro (ícone, título, descrição, status).
2. Clicar num card define `/#<id>` e mostra a rotina dentro do `RoutineStage` (botão "← Rotinas", título, descrição, painel de vidro).
3. A rotina é carregada sob demanda (`React.lazy` + `Suspense` com "Carregando rotina…").
4. "← Rotinas" e o botão voltar do navegador retornam à lista.
5. Abrir a URL com `/#<id>` vai direto para a rotina (deep-link).
6. Hash com id inexistente: mostra a lista com o aviso de que a rotina não existe.

## Critérios de aceite

- [x] Lista todas as rotinas do registro.
- [x] Abrir e voltar funcionam (teste `RoutineHub.test.tsx`).
- [x] Deep-link por hash.
- [x] Aviso para id inexistente.
- [x] Nenhuma rota extra em `src/app`.

## Fora de escopo

- Autenticação.
